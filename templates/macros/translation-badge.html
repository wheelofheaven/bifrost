{# translation-badge macro Surfaces a translated page's status as a small pill. Renders only when: - the page is being viewed in a non-English language, AND - `translation_status` is set to a known value Values map to: - "metadata_only" → yellow pill (title/description only) - "machine" → mauve pill (auto-translated body) - "ai_reviewed" → teal pill (AI-translated, then independently reviewed) - "human" → mint pill (fully translated) - "en_only" → grey pill (English fallback) Optional freshness data, written into [extra] by scripts/translation_audit.py: updated — `translation_updated`, the translation's last real change (YYYY-MM-DD) source — `source_updated`, the English page's last real change stale — `translation_stale`, the English changed after the translation sync — `translation_sync`, structural parity with the English, 0–100 The pill is marked "may lag" (dashed border, amber dot ring) when the English changed after the translation or structural parity is below 80. The dates go in the tooltip; the percentage stays in the data. Usage: {% import "macros/translation-badge.html" as translation_badge %} {{ translation_badge::render(status=page.extra.translation_status | default(value=""), lang=detected_lang, sync=page.extra.translation_sync | default(value=100)) }} #} {% macro render(status="", lang="en", updated="", source="", stale=false, sync=100) %} {% if lang != "en" and status %} {% set label = ""
