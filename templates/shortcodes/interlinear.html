{#- interlinear — a short passage set word by word: the original script, a transliteration, a gloss and a grammatical note under each word, so a reader without the language can see what the argument points at. Usage (one word per line: original | transliteration | gloss | note | *): {% interlinear(script="he", dir="rtl", caption="Genesis 1:26, opening words") %} וַיֹּאמֶר | vayyomer | and said | verb, singular אֱלֹהִים | Elohim | Elohim | noun, plural in form | * {% end %} script BCP 47 code of the original words, e.g. "he" (required). Not named `lang`: Zola defines `lang` itself inside a shortcode and it would shadow the argument. dir "rtl" lays the words out right to left (default "ltr") caption optional line under the strip (inline markdown) A trailing `*` column marks the words the surrounding prose is about; they take the accent. -#} {%- set _dir = dir | default(value="ltr") -%} {%- set _lines = body | trim | split(pat=" ") -%}
